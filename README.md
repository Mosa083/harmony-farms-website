##  Project Overview

Harmony Farms is a family-owned 15-hectare organic farming operation located in the Western Cape, South Africa, established in 2010. The farm specializes in producing high-quality, chemical-free, pesticide-free produce supplied directly to local consumers, regional restaurants, and Community Supported Agriculture (CSA) subscribers.

This repository contains the complete 5-page static website developed for Harmony Farms as part of the WEDE5020 Web Development project. The website aims to establish an online presence for the farm, increase product sales, educate visitors on sustainable agriculture, and facilitate customer inquiries.

---

##  Pages Included

The website consists of 5 main web pages structured using standard HTML5:

1. **`index.html` (Homepage)**
   - Hero banner displaying farm fields and quick navigation call-to-actions.
   - Key value highlights (100% Pesticide-Free, CSA Program, Eco-Friendly).
   - Newsletter subscription form and social media links.

2. **`about.html` (About Us)**
   - Detailed background and history of Harmony Farms (2010 to present).
   - Formal Mission and Vision statements[cite: 1].
   - Sustainable farming practices and local customer testimonials.

3. **`products.html` (Products & Services)**
   - Product catalog highlighting the Weekly CSA Harvest Box, Wholesale Supply, and Farm Tours.
   - Seasonal Produce Calendar presented in an organized HTML data table.

4. **`enquiry.html` (Product & Service Enquiry)**
   - Interactive HTML enquiry form for CSA subscriptions, wholesale quotes, and farm tour bookings.
   - HTML5 client-side input validation (`required`, proper input types).

5. **`contact.html` (Contact Us)**
   - Complete contact details, street address in the Western Cape, and operating hours.
   - Embedded interactive Google Map location.
